# Atxatlarge-code Tap

## How do I install these formulae?

`brew install atxatlarge-code/tap/<formula>`

Or `brew tap atxatlarge-code/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "atxatlarge-code/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
